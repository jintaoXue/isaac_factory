episode split $140/28/36$ (seed 42);
windows $20826/4331/5354$.
Input $T_{\mathrm{in}}{=}30$\,min, horizon $H{=}15$\,min.

Thresholds are selected on validation with report precision $\ge 0.80$, then frozen on test.
