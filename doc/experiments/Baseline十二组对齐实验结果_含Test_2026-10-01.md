# Baseline 十二组对齐实验结果（含 Test）

日期：2026-10-01

## 结果范围

本报告整理 B2（XGBoost）、B3（LSTM）、B4（GCN+GRU）和 B5（GAT+GRU）在 Start≤5、10、15 三档上的 train、validation 和 test 结果，共 12 组任务。

三份 split 使用同一套 factory_dense_i1_eval_tyx_7b2ab39_v1 评估契约：30 个历史窗口、20 个未来窗口、Min8、起点容差 3 窗口，validation 选择阈值后冻结到 test。数据为固定 208 episodes，train/validation/test 为 138/30/40。

Test 由 baseline_matched_v1_test_20261001_archivefix2.json 生成，使用各任务对应的冻结 checkpoint：cap=5 和 cap=10 从阶段 ZIP 归档读取，cap=15 从当前目录读取；没有重新训练，也没有用 test 重新选择阈值。

## Test 结果观察

- Start≤5：B2 的 test F1 最高（70.47%），B5 为 68.97%，B4 为 67.09%。严格 upcoming 召回最高的是 B3（9.32%）。
- Start≤10：B2 的 test F1 最高（62.13%），B5 接近（61.97%）；B3 的严格 upcoming 召回最高（7.78%）。
- Start≤15：B2 的 test F1 最高（58.98%）；B5 为 54.69%，B4 为 53.65%，B3 为 48.61%。B3 的严格 upcoming 召回最高（7.19%），但整体 P/R/F1 较低。
- 随 Start 范围扩大，四种 baseline 的整体 test F1 均下降；这与 validation 的总体趋势一致。

## 与 dev_tyx 主实验的对齐边界

本批结果在事件标签、Min8、未来网格、Start 三档、起点容差、ongoing/upcoming 分组、阈值冻结和主要报告字段上对齐 dev_tyx@7b2ab39 的评估契约。will15_*、严格 report 命中、剩余时间 MAE 和原因识别字段可按同名语义整理。

数值横向比较仍限于同一数据清单、split manifest 和 checkpoint。当前 baseline 使用固定 208-episode 数据包；仓库中已有的主实验参考主要是 validation 记录，不能把不同数据包或不同 split 的主实验数字直接与本表做差值。
